# Product Boundary

iRespond is one unified global community-action platform with multiple role-aware surfaces, not a collection of disconnected social products.

## Mobile-first priority

The iOS and Android application is the primary consumer and community interaction surface. Camera capture, geolocation, evidence, offline queues, low-bandwidth media, notifications, discovery, contribution, verification, and impact identity are first-class capabilities.

## Primary surfaces

- Mobile application: residents, volunteers, donors, verifiers, project participants, youth and community members.
- Responsive web: public discovery, deep project reading, account access and lightweight participation.
- Institutional console: NGOs, companies, foundations, governments, schools, alumni groups and faith/community organisations.
- API/event platform: trusted integrations, automation and ecosystem partners.

## Core lifecycle

See -> Report -> Verify -> Diagnose -> Create Project -> Mobilise -> Execute -> Measure -> Maintain -> Replicate.

## Contribution model

Money is only one contribution type. The platform also supports time, skills, materials, equipment, transport, knowledge, access, influence, care, approvals, space and project leadership.

## Trust boundary

A report is not automatically a verified fact, an approved project or a fundraising campaign. Verification, safeguarding, financial controls, technical approvals and project-risk tiers are explicit platform states.
